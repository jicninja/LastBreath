# Plan 011 — Asset pipeline Wave B (Unity import gate + first dogfood asset)

> Code + asset creation plan. Lands the Unity-side import gate (`ApprovedAssetImporter`, `ArtSyncVerifier`) and proves the art pipeline closes end-to-end on one real asset, replacing the placeholder cube from PLAN-010.

## Code deliverables

| Path | Purpose |
|---|---|
| `src/Assets/_Editor/Art/ApprovedAssetImporter.cs` | `[MenuItem("LastBreath/Art/Import Approved Assets")]`. Scans `art/*/manifest.yaml`; for each `approved == true && imported_at == null`: SHA-256 verifies `.glb` vs `imported_hash` (mismatch → log + skip), copies to `manifest.target_unity_path`, configures `ModelImporter` from `manifest.importer_settings` (unknown keys → warning, never throw), writes `imported_at` + `target_unity_guid` back |
| `src/Assets/_Editor/Art/ArtSyncVerifier.cs` | `[MenuItem("LastBreath/Art/Verify Sync")]` + headless mode (`-batchmode -executeMethod`) returning non-zero on drift. Re-hashes source `.glb` vs `imported_hash`; cross-checks live `ModelImporter` settings vs `manifest.importer_settings` |
| `src/Assets/Tests/EditMode/Art/ApprovedAssetImporterTests.cs` | Fixtures: importable, hash-mismatch (rejected), already-imported (skipped), unknown importer-setting key (warning, no throw) |
| `src/Assets/Tests/EditMode/Art/ArtSyncVerifierTests.cs` | Drift detection on a fixture where `imported_hash` no longer matches the live `.glb` |
| `scripts/check-art-sync.py` (modified) | `--deep` branch invokes `ArtSyncVerifier` via Unity headless |
| `.mcp.json` | Add `blender_mcp` server entry |
| `docs/registry/architecture.yaml::tooling.mcp_servers.blender_mcp.pin` | Fill git SHA at install |
