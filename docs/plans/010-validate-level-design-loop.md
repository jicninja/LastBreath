## Validation gate (binary pass / fail)

- [ ] `SCENE-CORREDOR-C7.unity` opens with zero compile errors
- [ ] `LastBreath/Level/Validate Scene` reports zero errors
- [ ] `LevelSpec_RoundtripsScene_IsIdempotent` (extended to load this scene) passes 3 runs in a row
- [ ] `c7.layout.yaml` is human-readable (a reviewer identifies each node without opening Unity)
- [ ] `/review-level --strict` → zero blocking violations
- [ ] `python3 scripts/check-art-sync.py` → exit 0 (trivially clean — no `art_assets` referenced)
- [ ] **Every editor verb ran via `unity-mcp`** — if the human dropped into Unity to fix something, that is a fail

## Failure path

Any item fails → write `What broke` in `session-0001.md` with the exact MCP verb gap / round-trip noise / idempotency hole. Set this plan to `paused`. Open a sibling plan that closes the specific gap (`PLAN-013-mcp-gap-fix`, etc.). Do not patch around the gap inside this plan.
